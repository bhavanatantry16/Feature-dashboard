Connect to GitHub, or explore in demo mode.

GitHub

Stored server-side. Scopes: repo (read), read:org, read:user.

Comma-separated. A plain org name pulls its most-recently-pushed repos.

Azure DevOps deployments (optional)

Paste the Azure DevOps project URL for each environment. Same project across all three slots is fine — the stage-name keywords in .env decide which release stage fills which slot.

One PAT for all three URLs. Create at dev.azure.com/<org>/_usersSettings/tokens.

View demo

Webhooks (optional, real-time)

Point your GitHub webhook to /api/webhooks/github with events: push, pull_request, pull_request_review, deployment_status, workflow_run, release. Set GITHUB_WEBHOOK_SECRET in .env and use the same secret.
